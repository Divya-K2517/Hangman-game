# Hangman

![Screen Recording 2024-12-24 at 6 06 21 PM (1)](https://github.com/user-attachments/assets/959d08c7-11c8-4cec-ad8a-dc90ed4f4286)


**Description:**  
The T-rex game that shows up when there is no internet  

**Technology:**  
Pygame library  

**Prerequisites/Instructions:**  
To start the game,
* install Python and the pygame library
* run main.py  

**Controls:**  
* press the space bar to make the dino jump  
* if the game ends, press "a" to restart
